# Instagram Backend (Console App)

A small Python console application that models basic Instagram features using object-oriented programming. Create users and posts, follow users, like posts, add comments, and view a feed of posts from followed users.

## Features

- Create users with an ID, username, and bio
- Create multiple posts for each user
- Like posts and track their like counts
- Add comments to posts
- Follow other users
- View posts from followed users in a feed

## Requirements

- Python 3

No external packages are required.

## Run the application

Clone the repository, open a terminal in the project directory, and run:

```bash
python main.py
